# Blockers and limits

- **Scope remains incomplete.** The current selected-library progress scan is 2,959/4,240; `libSceAgcDriver` is 97/167, gfx1013 forms are 1,512/1,560, and the recompiler still has 128 throw sites. The user's all-functions/all-paths target has not been met.
- **Behavioral evidence.** Many remaining exports have no confirmed argument ABI or public behavior contract in this repository. A name or NID is not enough to implement correct behavior. Continue only where public documentation or a meaningful synthetic test oracle establishes semantics.
- **System-library follow-up audit.** No additional service function met that standard in this pass. `sceAppContentDownloadDataGetBlockSize` forwards to an external service whose result/block semantics are explicitly unknown in the repository debt notes; other remaining service exports still lack ABI or behavior fixtures. Sysmodule's implemented load/refcount path already has invalid-ID regression coverage. These are evidence gaps, not permission to add success stubs.
- **Shader follow-up audit.** The 15 DS_SRC2 64-bit LDS forms now pass a 32-lane GPU execution test; floating min/max edge semantics (NaNs, signed zero, infinities, denormals) still need targeted oracles. Remaining unsupported throw sites primarily involve format/resource materialization and decoding guards; 64-bit image atomic fallbacks need reachability and instruction-semantics work before they can be changed safely. 64-bit DS_SRC2 GDS remains explicitly unsupported.
- **Scalar scratch loads.** `core/shader/recompiler/Translation/src/MemoryInstructions/ScalarBufferInstructions.cpp::TranslationContext::sScratchLoad` rejects three decoded forms. Existing `core/libs/tests/ScalarScratchLoad.cpp` checks decoding and expects translation to throw; it is not a semantic oracle. A prior lowering was reverted because lane/wave scratch mapping was unresolved. References: [AMD RDNA 2 ISA](https://www.amd.com/content/dam/amd/en/documents/radeon-tech-docs/instruction-set-architectures/rdna2-shader-instruction-set-architecture.pdf) and [LLVM AMDGPU usage](https://llvm.org/docs/AMDGPUUsage.html).
- **Full build/test suite.** A prior full CTest run on the earlier source revision had 6,492 passes, 122 failures, and 37 skipped tests. A targeted newer-source build passed the selected tests below, but the entire runtime and full suite have not been rebuilt/retested after the merge. Windows Security quarantined some generated AGC executables in the earlier full build; settings were not changed.
- **Current full Release build.** The all-target Ninja build stopped at the post-link `objcopy` step for `agc_shader_replay.exe`. Windows Security's read-only threat history identifies it as `Trojan:Win64/ShellCode.MKA!MTB` (ThreatID `2147960850`, severity 5) and blocks access; all 413 patched PRX output paths existed (408 refreshed during this attempt). No antivirus exclusion or protection change was made. This is an environment-level blocker for completing the all-target build and any affected AGC tool tests.
- **Runtime compatibility.** No homebrew application, actual PS5 executable, GTA VI, or first-frame rendering was tested. Tests used public source and synthetic/upstream fixtures. No claim of GTA VI compatibility is supported.
- **Vulkan evidence.** Two AGC tests passed with Khronos validation enabled on this host, but this covers only their exercised operations; it is not proof of complete rendering, presentation, synchronization, or guest GPU equivalence.
- **Scalar buffer store scope.** The new DWORD/X2/X4 forms passed synthetic aligned, in-bounds GPU writes with one active lane per wave. Other address-mode combinations, out-of-bounds behavior, unusual EXEC masks, and console-specific visibility semantics are not established by these tests.
- **Scalar buffer atomic scope.** Ten scalar buffer RMW operators, compare-swap, and INC/DEC pass one-wave GPU tests at 32 and 64 bits for GLC return/no-return. Latest focused IR+GPU test pair passed 2/2. Multi-wave contention, alternate offsets, descriptor-boundary faults, and memory-order interactions are not yet verified.
- **Scalar-address atomics.** Only `S_ATOMIC_ADD` DWORD/X2 (0x82/0xa2) is implemented; one-wave RTX 4060 tests pass for GLC/no-GLC. Other arithmetic/bitwise/CAS/INC/DEC scalar-address forms remain unsupported. Their base+offset route uses the existing physical-address path but needs independent opcode/operand and result tests before translation.
- **Scalar raw stores.** `S_STORE_DWORD/X2/X4` now execute through the existing physical-address backend when the guest range has a valid runtime BDA mapping. An unregistered pointer correctly raises a BDA fault; the passing test registers the range via a buffer descriptor. Scratch stores remain blocked on precise per-lane scratch-address mapping and cannot reuse this raw BDA path blindly.
- **AGC host-retile fast path.** The forced `agc_storage_write_back_host_retile` test can fail its route-count assertion for a two-mip 240x135 linear texture because `core/libs/prx/libSceAgcDriver/src/Texture.cpp::linearRows` requires every mip to be non-tail. Diagnostic output showed the path was rejected before host import (`0 direct, 0 host-blocked, 1 other`); per-texel and row-padding checks passed via scratch writeback. Enabling direct host retile for tail mips lacks a correctness oracle and was not attempted. Current shell lacked `ctest`/CMake executables for a repeat run.
- **Debug configuration.** Debug build was not run.
